# Личный каталог фильмов

Учебный проект для поиска фильмов и ведения личного каталога.

- Сайт: [kinova-sigma.vercel.app](https://kinova-sigma.vercel.app/).
- Публичный код: [GitHub — kinova](https://github.com/maliksuleimenov11-dotcom/kinova).
- Данные фильмов: [Kinopoisk API Unofficial](https://kinopoiskapiunofficial.tech/).

## Состояние проекта

Возможности первой версии реализованы и размещены на Vercel. Пользователь подтвердил работу настоящего поиска, а затем сообщил «всё работает» после предложенной проверки добавления, переноса, оценки, отзыва, обновления страницы и сайта на телефоне. Это подтверждение пользователя; агент не выполнял эти действия в браузере.

Автоматические проверки пройдены на подменённых элементах страницы, API и localStorage. Отдельная проверка точной ширины 375px, размеров элементов 44px, клавиатуры, фокуса и отсутствия ключа в Network браузера пока не подтверждена.

## Возможности

- Поиск по названию кнопкой «Найти» или Enter, без запросов при наборе.
- Первая страница карточек с постером, названием, годом и рейтингом API; заглушки отсутствующих данных.
- Списки «Хочу посмотреть» и «Просмотрено», счётчики и перенос в обе стороны.
- Одна запись на ID фильма; одинаковые названия с разными ID считаются разными фильмами.
- Личная оценка от 1 до 10 и необязательный отзыв до 500 символов, сохранение и отмена.
- Сохранение каталога в localStorage и восстановление списков, порядка, оценки и отзыва после перезагрузки.
- Сообщения об отсутствии результатов, ошибке сети, недоступности сервиса, квоте API и частых запросах к сайту.
- Русский интерфейс; предусмотрены мобильная вёрстка, подписи полей и видимый фокус.

## Как пользоваться и проверить

1. Откройте сайт, введите «Матрица» и нажмите «Найти». Во время ввода запросов нет; состав выдачи зависит от API.
2. Добавьте фильм в «Хочу посмотреть». Найдите его снова: вместо кнопок добавления должен быть статус, без копии в каталоге.
3. Нажмите «Уже посмотрел», затем «Хочу пересмотреть»: фильм переносится, счётчики обновляются.
4. Откройте «Оценка и отзыв», выберите оценку и напишите текст. Сохраните; рейтинг API не должен измениться.
5. Измените личные поля и отмените: останутся прежние значения. «Не указана» и пустой отзыв позволяют очистить поля.
6. Проверьте 500 и 501 символ: лишний текст не обрезается, сохранение показывает ошибку. Счётчик считает кодовые точки Unicode после удаления пробелов по краям; обычное эмодзи занимает одну, составное — несколько.
7. Перенесите фильм и обновите страницу: каталог и личные поля должны остаться.
8. Проверьте Tab/Enter и ширину 375px: поля и кнопки доступны, фокус виден, горизонтальной прокрутки нет, поля высотой от 44px и области кнопок от 44 × 44px.

Одновременно открыта одна форма. Открытие формы другого фильма отменяет предыдущий несохранённый ввод. Поиск и обновление каталога сохраняют открытый черновик; F5 без «Сохранить» его сбрасывает. Перенос редактируемого фильма заблокирован.

## Ограничения хранения

Каталог доступен только в этом браузере для текущего адреса сайта. Очистка данных сайта удалит фильмы; приватный режим может ограничить срок хранения. Каталог не синхронизируется между устройствами, браузерами и вкладками. Используйте одну вкладку: более поздняя запись другой вкладки может заменить изменения. У локального сайта и сайта Vercel отдельные каталоги.

При ошибке записи изменение не применяется: прежние данные остаются, форму можно сохранить повторно. При ошибке чтения или повреждении данных изменение каталога блокируется без перезаписи; поиск работает. Автоматического восстановления повреждённых данных нет. Не очищайте настоящий каталог ради теста.

Хранилище kinova.catalog читает версии 1 и 2 и записывает версию 2. Старые данные не перезаписываются при загрузке; перевод формата происходит при успешном изменении. Ключ API и результаты поиска в каталог не записываются.

## Стек и безопасность

HTML, CSS и JavaScript для страницы, серверная функция Node.js на Vercel. База данных и регистрация не используются.

Браузер → /api/search → Kinopoisk API Unofficial. Только сервер читает KINOPOISK_API_KEY и передаёт его API в заголовке. В Git, клиентские файлы, примеры и логи ключ не добавляется. Пользователь самостоятельно настроил Secret-переменную для Production на Vercel; агент значение не получал.

На Vercel настроено правило Request Path → Starts With → /api/search: Fixed Window, 10 запросов за 60 секунд на IP, действие 429. До подключения ключа проверен общий порог для /api/search и /api/search.js: первые десять чередующихся запросов получили 503, затем оба маршрута — 429. Это не защита общей квоты от множества IP; счётчики хостинга могут зависеть от региона. Другие домены проекта отдельно не проверены.

Страница по HTTP проверена (200); /.env.local, /.git/config, /server.cjs, /tests/search.cjs и /README.md дали 404. /api/search.js — дополнительный маршрут функции, исходник не раскрывает. Клиент различает 429 хостинга с произвольным телом и ответ API_LIMIT от сервера. Обновлённая обработка подтверждена в опубликованном script.js.

В Network браузера дополнительно проверьте запрос /api/search: ключа в его заголовках и ответе быть не должно. Постеры загружаются отдельно с внешних адресов.

## Локальный запуск

1. Установите [Node.js 22.x](https://nodejs.org/) и откройте новый терминал.
2. В папке проекта скопируйте .env.example в .env.local. Самостоятельно задайте значение KINOPOISK_API_KEY в редакторе; ключ не отправляйте в чат и не вводите в команду терминала.
3. Выполните npm start и откройте http://localhost:3000. Зависимостей нет, npm install не требуется.
4. Для остановки нажмите Ctrl+C. После изменения окружения перезапустите сервер.

.env.local исключён из Git. .env.example остаётся с пустым значением. Открытие HTML двойным щелчком не запускает серверную функцию.

## Проверки и сборка

- npm test — воспроизводимые проверки без ключа, настоящего API и изменения вашего каталога.
- npm run build — сборка без ключа в dist: только index.html, styles.css и script.js.

Проверены поиск и ошибки, дубли, оба списка, перенос, сохранение и восстановление, сбои хранилища, повреждённые данные, совместимость формата, оценка, 500/501 символ, эмодзи, черновик, отмена и HTML как текст. Таймеры моделируются. Это проверки логики с подменой элементов страницы, а не полноценный браузерный тест.

Сборка и повторная сборка проверены: три файла совпадают с исходниками. Посторонние файлы в dist останавливают сборку без автоматического удаления. Файл окружения не копируется. dist исключён из Git.

## Размещение на Vercel

Репозиторий подключён к Vercel; push автоматически запускает размещение. В vercel.json: Other, команда npm run build, Output Directory dist, функция api/search.js с максимумом 15 секунд. В package.json закреплён Node.js 22.x. .vercelignore исключает локальное окружение и служебные файлы при загрузке CLI; публичные файлы ограничены папкой dist.

Для повторного размещения сначала настройте правило Firewall без настоящего ключа. Затем самостоятельно добавьте KINOPOISK_API_KEY как Secret для Production и выполните Redeploy. Preview ключ не получает. Изменения окружения применяются к новому размещению. [Документация окружения Vercel](https://vercel.com/docs/environment-variables/managing-environment-variables).

Следите за расходом запросов в личном кабинете Kinopoisk API Unofficial. Для отключения настоящего поиска удалите серверную переменную ключа и выполните Redeploy. Прежние размещения сохраняют прежнее окружение: при необходимости отдельно ограничьте доступ к ним в Vercel. Платные услуги автоматически не подключались.
