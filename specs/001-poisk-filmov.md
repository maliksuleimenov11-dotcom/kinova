# 001 — Поиск фильмов и карточки

Статус: первый шаг реализован после «делай» и принят пользователем ответом «да». Проверена логика с подменёнными элементами страницы. Сервер и API ещё не подключены.

## Для кого и зачем

Для человека, который хочет найти фильм по названию и увидеть основные сведения перед добавлением в личный каталог. Это первая функция; сохранение, списки, оценка и отзыв получат отдельные спецификации.

## Что должно быть

- Поле «Название фильма» и кнопка «Найти». Пробелы по краям запроса убираются. Пустой запрос не отправляется: «Введите название фильма».
- Ввод текста сам по себе не вызывает API. Поиск запускается кнопкой; Enter в форме равнозначен её нажатию.
- Пока идёт поиск, видна надпись «Ищем фильмы…», повторная отправка заблокирована. Старые результаты очищаются, чтобы не спутать их с новым поиском.
- Браузер отправляет название своей серверной функции. Сервер читает KINOPOISK_API_KEY из окружения и запрашивает Kinopoisk API Unofficial. Ключ не передаётся браузеру.
- Показывается первая страница выдачи API в исходном порядке. Карточка содержит устойчивый ID фильма в данных, постер, название, год и подписанный рейтинг API.
- Если русского названия нет, использовать доступное оригинальное; если названия нет вообще — «Без названия». Для отсутствующих года, рейтинга и постера — «Год не указан», «Нет рейтинга», «Нет постера». Ошибка загрузки картинки также показывает заглушку.
- Нет совпадений: «Ничего не найдено. Попробуйте другое название».
- Сеть или недоступный сервис: «Не удалось выполнить поиск. Проверьте соединение и попробуйте ещё раз».
- Лимит запросов или исчерпанная квота, подтверждённые ответом API: «Лимит API исчерпан. Попробуйте позже». Не обещать точное время восстановления без данных API.
- Ошибка настройки или авторизации сервера: «Поиск временно недоступен». Не показывать посетителю технический ответ или ключ.
- После ошибки можно повторить поиск кнопкой. Автоматических повторов нет. Сервер ограничивает время ожидания ответа API.
- Русский интерфейс, подписи полей, доступные сообщения состояния, видимый фокус. На 375px нет горизонтальной прокрутки; поля высотой от 44px, кнопки с областью нажатия от 44 × 44px.

## Примеры

1. Ввести «Матрица»: до нажатия «Найти» запросов нет. Нажать кнопку — появляются загрузка, затем карточки либо соответствующее сообщение.
2. Ввести только пробелы и нажать «Найти»: подсказка о пустом названии, запросов нет.
3. Смоделировать пустую выдачу: видно «Ничего не найдено…», карточек нет.
4. Смоделировать отсутствие рейтинга и сломанный постер: видны «Нет рейтинга» и «Нет постера», карточка остаётся читаемой.
5. Смоделировать сбой сети, затем восстановить соединение и повторить поиск: сначала понятная ошибка, затем можно получить результаты.
6. Смоделировать ответ об исчерпании квоты: видно сообщение о лимите, повторных запросов без нажатия нет. Реальную квоту ради проверки не расходовать.
7. Быстро нажать «Найти» несколько раз во время загрузки: одновременно выполняется один поиск.

## Ограничения

- Без добавления в каталог, localStorage, отзывов, личных оценок, фильтров и пагинации в этой функции.
- Точный состав выдачи меняется у поставщика; не проверять фиксированное число фильмов или конкретный рейтинг.
- Перед реализацией сверить актуальный endpoint, поля ответа и коды ошибок с документацией API. Не считать любой отказ авторизации исчерпанием квоты.
- Никакого настоящего ключа в примерах, Git, клиентском коде и логах. Без ключа сервер сообщает о недоступности поиска безопасным текстом.
- Для воспроизводимых ошибок использовать подменённые ответы. Реальный запрос — отдельная проверка после самостоятельной настройки ключа пользователем.
- Публичное размещение выполняется отдельным шагом проекта после проверки серверной защиты и окружения.

### Шаги

Выполнять только после «делай», по одному шагу с остановкой для проверки.

1. [x] Форма и состояния на тестовых данных. На экране поле, кнопка и карточки. Проверка: пустой ввод; поиск по кнопке; ширина 375px. Реального API пока нет, это явно обозначено.
2. [ ] Серверная функция и настоящий поиск. Проверка: пользователь самостоятельно задаёт ключ; поиск выдаёт карточки; в браузере ключ отсутствует.
3. [ ] Ошибки и завершение функции. Проверка: подменённые пустая выдача, ошибка сети и лимит; повторный поиск; обновлённые возможности и проверки README. Дополнительно проверить остальные пункты «Готово, когда».
