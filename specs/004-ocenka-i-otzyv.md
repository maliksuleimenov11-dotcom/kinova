# 004 — Личная оценка и отзыв

Статус: первый шаг принят пользователем для коммита. После «делай дальше» реализован второй шаг — отзыв и счётчик. Автоматические проверки пройдены, ручная проверка и третий шаг остаются впереди.

## Для кого и зачем

Для владельца каталога, который хочет помнить свои впечатления о фильме и отличать собственную оценку от рейтинга API.

## Что должно быть

- В карточке фильма личного каталога есть подпись «Моя оценка: не указана» или «Моя оценка: 8 из 10». Рейтинг API остаётся отдельным полем.
- Оценку и отзыв можно задать в любом из двух списков. Они принадлежат фильму, а не списку, и сохраняются при переносе.
- Кнопка «Оценка и отзыв» открывает форму внутри карточки. Одновременно открыта одна форма; при открытии другой несохранённый ввод предыдущей отменяется. О таком поведении сообщить рядом с формой.
- Форма содержит подписанные поля «Моя оценка» (выбор «Не указана» или целого числа от 1 до 10) и «Отзыв» (многострочное поле), а также кнопки «Сохранить» и «Отмена».
- Оба поля необязательны: можно сохранить только отзыв или только оценку. Выбор «Не указана» удаляет личную оценку; пустой отзыв удаляет прежний текст.
- Отзыв — до 500 символов после удаления пробелов по краям; переносы строк внутри сохраняются. Рядом показывается счётчик длины сохраняемого текста, например «125 / 500». Для одинакового подсчёта в форме и хранении использовать число кодовых точек Unicode: обычное эмодзи считается одним символом, составное может занимать несколько.
- Текст длиннее 500 символов не обрезается молча и не сохраняется. Показать «Отзыв должен быть не длиннее 500 символов», оставить форму открытой и сохранить ввод. Можно исправить текст.
- Неверная оценка, попавшая в обработчик в обход поля выбора, не сохраняется: «Выберите целую оценку от 1 до 10 или „Не указана“».
- «Сохранить» обновляет существующий фильм по ID без добавления новой записи и без изменения порядка карточек, статуса и счётчиков. При успехе форма закрывается, отображается оценка и непустой отзыв, появляется «Оценка и отзыв сохранены».
- «Отмена» закрывает форму без изменения каталога. Повторное открытие показывает сохранённые значения.
- После открытия формы фокус на поле оценки; после сохранения или отмены — на кнопке «Оценка и отзыв» той же карточки. Ошибка валидации переводит фокус в неверное поле.
- Пока форма открыта, перенос редактируемого фильма недоступен. Новый поиск и его ошибки не закрывают форму и не теряют черновик. Если другая операция каталога перерисовывает карточки, черновик и фокус сохраняются.
- Отзыв отображается как обычный текст с переносами строк и переносом длинных слов. HTML не выполняется, ссылки автоматически не создаются.
- Данные записываются в localStorage и восстанавливаются при открытии страницы. Ввод до нажатия «Сохранить» не сохраняется.
- Ошибка записи оставляет старые значения в каталоге и хранилище; форма с введёнными значениями остаётся открытой, можно повторить. Применяются безопасные сообщения и блокировка изменения при ошибке чтения из спецификации 003.
- Русский интерфейс, подписи полей, сообщения ошибок и успеха доступны для программ чтения с экрана. Поля высотой от 44px, кнопки с областью от 44 × 44px, видимый фокус, работа при ширине 375px без горизонтальной прокрутки.

## Примеры

1. Открыть форму, выбрать 8, написать «Хочу пересмотреть», сохранить: видны «Моя оценка: 8 из 10» и отзыв. После F5 они остаются; рейтинг API не изменился.
2. Сохранить оценки 1 и 10: обе допустимы. Подменённые 0, 11, 2.5 и нечисловое значение отклоняются без изменения записи.
3. Ввести отзыв из 500 букв: сохранение работает. Ввести 501: сообщение об ограничении, текст остаётся в форме. Удалить одну букву и сохранить успешно.
4. Ввести «  Отличный фильм  »: сохраняется «Отличный фильм», счётчик показывает 14. Пустой отзыв и «Не указана» очищают оба личных поля.
5. Изменить оценку и текст, нажать «Отмена», снова открыть форму: прежние значения не изменились.
6. Перенести оценённый фильм в другой список и перезагрузить: оценка и отзыв сохранены, второй записи с тем же ID нет.
7. Смоделировать ошибку записи при сохранении: старые значения остаются, черновик доступен; после восстановления записи повторить успешно.
8. Открыть каталог из прежней версии без личных полей: все фильмы на месте, оценка не указана, отзыв пуст.
9. Ввести `<b>Фильм</b>` или длинное слово: текст отображается буквально, не ломает ширину карточки.
10. Открыть форму, начать отзыв, выполнить поиск или добавить другой фильм: форма и черновик сохраняются. При открытии формы другого фильма предыдущий несохранённый ввод отменяется.

## Ограничения

- Без публикации отзывов, отправки серверу, регистрации и синхронизации устройств. Действия с личными полями не вызывают API.
- Для ясного разделения формата сохранить `kinova.catalog`, но перейти к `version: 2`: добавить к фильму `personalRating` (null или целое 1–10) и `review` (строка до 500 кодовых точек после trim). Рейтинг API по-прежнему называется `rating`.
- Читать версии 1 и 2. Версию 1 восстанавливать в памяти с `personalRating: null` и `review: ""`; исходную строку не перезаписывать при загрузке. При первом успешном изменении записывать весь каталог как версию 2. Если запись не удалась, исходные данные остаются.
- Все операции сохранения (добавление, перенос, оценка) обязаны сохранять новые поля; прежняя нормализация не должна удалять их. Неизвестные версии и неверные данные обрабатывать безопасно по спецификации 003. Её правило единственной версии 1 заменяется поддержкой версий 1 и 2.
- Не обрезать неверный отзыв из сохранённых данных автоматически: блокировать изменение повреждённого каталога без перезаписи. Существующие правила проверки ID и объединения повторов сохраняются.
- Не внедрять автосохранение черновика, богатый редактор и удаление фильма. Одновременно использовать одну вкладку, как и в спецификации 003.
- Старые непроверенные браузерные пункты и настоящий API не считать завершёнными при добавлении этой функции.
