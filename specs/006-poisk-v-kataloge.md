# 006 — Поиск в личном каталоге

Статус: реализовано после «давай делай». Автоматические проверки и сборка пройдены; ручная проверка пользователем ожидается. Коммит и публикация ещё не выполнены.

## Для кого и зачем

Для владельца большого каталога, которому нужно быстро найти сохранённый фильм, не расходуя запросы внешнего API.

## Что должно быть

- В разделе «Мой каталог» отдельная форма «Название в моём каталоге», кнопки «Найти в каталоге» и «Показать все». Подсказка: «Только сохранённые фильмы. Лимит API не расходуется».
- Поиск применяется по кнопке или Enter, не при наборе текста. Проверяется часть отображаемого названия без учёта регистра, пробелы по краям запроса удаляются. Русское название имеет приоритет, при его отсутствии используется оригинальное, затем «Без названия».
- Один запрос применяется к обоим спискам. Фильмы остаются в своих списках и прежнем порядке. При активном непустом запросе счётчики показывают «Найдено: N из M», где M — полное число фильмов соответствующего списка.
- Если сохранённые фильмы в списке есть, но совпадений нет: «В этом списке ничего не найдено. Измените запрос или нажмите „Показать все“». Если список вообще пуст, остаётся прежнее сообщение о добавлении фильма из поиска.
- Пустой запрос и «Показать все» возвращают все карточки. Кнопка также очищает поле; фокус возвращается к полю каталога. Общая подсказка сообщает, какой запрос применён, или что показаны все фильмы; изменения доступны программам чтения с экрана.
- Ввод до 200 символов; превышение, попавшее в обработчик в обход поля, не применяется и показывает понятную ошибку. Результаты предыдущего поиска остаются.
- Добавление, перенос и сохранение оценки/отзыва при активном поиске обновляют видимость и счётчики. Поиск только скрывает неподходящие карточки, не удаляет фильмы и не меняет localStorage.
- Скрытая форма оценки и отзыва сохраняет черновик: после «Показать все» он доступен. Поиск в каталоге не отменяет форму и не меняет личные данные.
- Поиск работает без API, в том числе при исчерпанной квоте или отсутствии сети, если страница уже открыта и каталог восстановлен. Внешний поиск в верхней части страницы остаётся отдельным.
- Русские подписи, видимый фокус, поля высотой от 44px, области кнопок минимум 44 × 44px, отсутствие горизонтальной прокрутки на 375px.

## Примеры

1. Сохранены «Матрица» и «Дюна». Ввести « МАТР », нажать «Найти в каталоге»: видна только «Матрица»; ввести другой текст без отправки — текущий результат не меняется.
2. «Матрица» есть в обоих списках с разными ID: оба фильма видны. Совпадение названия не объединяет записи.
3. Ввести неизвестное название: фильмы скрыты, видно сообщение об отсутствии совпадений. Нажать «Показать все»: полный каталог возвращается без потерь и записи в хранилище.
4. Перенести найденный фильм: он появляется в другом списке, счётчики обоих списков пересчитаны с учётом запроса.
5. Открыть отзыв, ввести черновик, скрыть фильм поиском и показать все: текст не потерян.
6. Отправить только пробелы: показаны все сохранённые фильмы. После F5 запрос сброшен, каталог остаётся.
7. Поиск с отключённой сетью работает по уже загруженному каталогу; сетевых запросов и расхода API нет.

## Ограничения

- Без фильтров по оценке, сортировки, поиска по отзыву и изменения серверной функции.
- Запрос каталога хранится только в памяти страницы. Формат localStorage версии 2 не меняется.
- Не сравнивать названия по смыслу, не исправлять опечатки и не приравнивать автоматически «е» и «ё».
- При ошибке восстановления хранилища сохраняются существующие блокировки и сообщения; поиск по пустому каталогу их не снимает.
- Не считать подтверждёнными ранее открытые детальные проверки клавиатуры и размеров элементов.

## Готово, когда

- [ ] Проверены поиск по части названия, регистр, пробелы, пустой запрос и сброс.
- [ ] Корректны оба списка, порядок, счётчики, пустой каталог и отсутствие совпадений.
- [ ] Поиск не обращается к API, не пишет в localStorage и не теряет фильмы или черновик.
- [ ] После добавления, переноса и редактирования отображение соответствует активному запросу.
- [ ] Прежние проверки и сборка проходят; результаты и ограничения описаны в README.
- [ ] Вручную проверены клавиатура и 375px либо честно указано, что это не выполнено.
- [ ] Пользователь проверил результат; коммит и push — только после отдельного «да».
